# Конституция relay

## Основная конституция

Общие технические правила находятся в Service Kit. Перед планированием,
проверкой и реализацией ОБЯЗАТЕЛЬНО прочитать полностью
[основную конституцию](../../../servicekit/.specify/memory/constitution.md),
разрешая путь относительно `.specify/memory/constitution.md` этого репозитория.
Зафиксировать Git commit источника и наличие незакоммиченных изменений файла.

Если соседний источник отсутствует, прочитать файл из актуального `main`
[endless-net/service-kit](https://github.com/endless-net/service-kit/blob/main/.specify/memory/constitution.md)
через штатный авторизованный Git/GitHub и зафиксировать точный commit.
Если оба источника недоступны, сообщить блокер до изменения затронутых артефактов.
Ссылка сама по себе не означает, что документ прочитан.

Если нужны подробности, переходить к применимому стандарту, его example
и документации владельца. Не копировать общие технические правила в этот файл.
Учитывать область действия каждого стандарта и effective локальный AGENTS.md;
прямые инструкции пользователя имеют приоритет.

## Локальные дополнения

В этом разделе указывать только принятые особенности текущего репозитория:
причину, область, заменяемое общее положение и действующее локальное правило.
Отсутствие локального дополнения не отменяет применимое общее правило.
Подключение не принимает proposed решения, не разрешает запись в другие
репозитории, реализацию, commit/push или deployment вне запроса пользователя.
