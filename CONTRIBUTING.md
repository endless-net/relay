# Contributing

Contributions are welcome through GitHub pull requests.

Before opening a pull request:

1. keep the change focused and avoid compatibility fallbacks for superseded behavior;
2. run the repository's documented verification commands;
3. update tests and public documentation for behavior or contract changes;
4. confirm that no credentials, private keys, production inventory, or private user data are included;
5. sign off every commit to certify the Developer Certificate of Origin.

Use `git commit --signoff` or add the following trailer to each commit:

```text
Signed-off-by: Your Name <your-email@example.com>
```

The sign-off certifies the Developer Certificate of Origin 1.1:
https://developercertificate.org/

Security vulnerabilities must be reported through GitHub's private
vulnerability reporting flow rather than a public issue.
