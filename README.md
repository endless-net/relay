# Relay

Runtime009 содержит две роли одного producer:

- `relay-coordinator`: registry, leases, durable epochs и направленная авторизация через Network Coordinator.
- `relay`: публичные `relay-v1-tls` sessions и прямой mesh с конечными Relay.

Схемы/SDK — в [api](api/README.md). Published pins: `relay/api v0.2.0`,
`coordinator/api v0.1.0`, без replace. API/runtime версии независимы.
Целевая среда — Linux amd64; конфигурация не выполняет deployment.

## Конфигурация и команды

Переменные env/v11; ошибочные сочетания или CLI flags прерывают запуск.

| Переменная | Роль / смысл |
| --- | --- |
| ENDLESSNET_RELAY_LISTEN | Dataplane public TLS address, default :9443 |
| ENDLESSNET_RELAY_MESH_LISTEN | Dataplane mesh address, default :9444 |
| ENDLESSNET_RELAY_MESH_ADDRESS | Обязательный advertised mesh host:port |
| ENDLESSNET_RELAY_ID | Стабильный уникальный ID dataplane, одна path component |
| ENDLESSNET_RELAY_COORDINATOR_ADDRESS | Relay Coordinator host:port для dataplane |
| ENDLESSNET_RELAY_CONTROL_LISTEN | Coordinator gRPC address, default :9445 |
| ENDLESSNET_RELAY_UPSTREAM_URL | Network Coordinator HTTPS URL |
| ENDLESSNET_RELAY_DATABASE_URL | Relay-owned PostgreSQL DSN, без default |
| ENDLESSNET_RELAY_DATABASE_IDENTITY | Обязательный exact SPIFFE ID PostgreSQL endpoint |
| ENDLESSNET_RELAY_TLS_CERT / ENDLESSNET_RELAY_TLS_KEY | Только public TLS certificate/key |
| ENDLESSNET_RELAY_WORKLOAD_API | Default unix:///run/spire/sockets/agent.sock |
| ENDLESSNET_RELAY_HTTP_LISTEN | Loopback diagnostics, default 127.0.0.1:9190 |
| ENDLESSNET_RELAY_OTEL_ENDPOINT | Optional HTTPS OTLP URL без userinfo/query |

`--version` и `--check-config` не открывают сеть. `relay-coordinator --migrate`
применяет собственные Goose domain migrations отдельно от runtime startup.
Это не host provisioning; обычный запуск требует подготовленную схему.

Internal identities: `spiffe://endlessnet.ru/service/relay/<relay_id>`,
`spiffe://endlessnet.ru/service/relay-coordinator`, upstream
`spiffe://endlessnet.ru/service/coordinator`. Workload API SVID вращается в памяти;
static workload certificates и plaintext fallback запрещены. Public TLS
certificate — отдельная граница. SPIRE и доверенное время настраиваются внешне.

`/healthz`, `/readyz`, `/metrics` — на настроенном loopback. Registry/trust/SVID
failure снимает готовность; обязательная фатальная ошибка останавливает процесс.
Optional exporter не влияет на право и не блокирует critical path.

## Средний профиль

На dataplane до 1000 сессий и 100 Мбит/с decoded входящего payload.
Encoding/TLS/egress считаются отдельно. Session queue32/256КиБ,
mesh queue256/4МиБ, global64МиБ. Handshakes64 concurrent,100/s global,
10/s source; cache10000, исходящие RPC128. Payload≤65536 bytes, line≤147456.
Duplicate/unknown/malformed input закрывает сессию; переполнение queue
отбрасывает новый frame и учитывается в bounded counters.

Instance lease30с; session15с/renew5с. Control heartbeat5с обновляет trust
через тот же RPC чаще минимально требуемого instance renewal10с.
Trust/allow≤10с от начала авторитетной проверки; другие expiry сокращают срок.
Revoke Relay-пути≤15с — цель приёмки. Перед отправкой повторная проверка права.
Новый boot того же relay_id не захватывает живой прежний instance lease;
до его expiry новый процесс может получить безопасный отказ запуска.

## Проверка и ограничения

Базовый unit-only CI: [AGENTS.md](AGENTS.md), `python3 -B scripts/ci.py check`.
Для private producer API нужен protected repository-scoped read-only secret
`PRODUCER_API_READ_TOKEN`; отсутствие доступа завершает fetch/check ошибкой.
External PR получает пустой secret, без fallback на local checkout.
Secret содержит fine-grained token только для Coordinator с Contents: read.
Он настраивается отдельно от исходного кода перед remote CI.

SQL: `sqlc v1.30.0`, `sqlc generate`, повтор даёт те же generated bytes.
Transport отдельно:

```bash
go test -race -tags=integration ./internal/relay ./internal/mesh ./internal/tlsconfig ./internal/relaycontrol ./internal/authz
```

PostgreSQL отдельно: `go test -tags=postgres ./internal/store` с явно заданным
`RELAY_TEST_DATABASE_URL` изолированной пустой тестовой БД. Suite применяет
domain migrations; production DSN использовать нельзя. Plain Unix socket
подключение существует только в build-tagged test fixture, не в runtime.

Настоящий Client/Coordinator/Signing E2E, полный1000-session/30-minute load,
SPIRE rotation/outage и внешняя platform acceptance не подтверждаются unit pass.
Факты/ограничения сохраняются в workspace tasks. CI build/publish требует
clean exact committed source; dirty local candidate собирается напрямую без release.

Product fixture: `go test -tags=product ./tests/product`; он требует
RELAY_POSTGRES_ROOT с распакованным PostgreSQL18 под /tmp/relay009-pg.*.
`-tags=product,load -run TestRuntimeMeshCapacity` проверяет1000 sessions на
каждом реальном dataplane за30мин после30с прогрева трафиком. Workload API
и domain authorities здесь синтетические; настоящая SC-006 не заявляется.


Текущий runtime — локальный candidate009 на опубликованном APIv0.2.0
(main6357f513bb6a2c0db56b6de6b926aad115930818). Mesh protocol_version=1
меняется hard cutover: новое поле source authorization deadline обязательно;
старый формат не принимается, параллельных версий нет. Sender/receiver
expiry bounds реализованы; окончательная локальная нагрузочная приёмка PASS.
Runtime ещё не публиковался и не развёртывался.
Безопасные public error values — фиксированные коды invalid_auth/auth_timeout/
unsupported_protocol/invalid_credential/session_rejected/invalid_frame/
frame_too_large/self_target/bandwidth_limit/pair_denied/mesh_unavailable/
peer_unavailable/peer_fenced/peer_queue_full, без исходных ошибок.

OTel spans покрывают control/upstream, registry queries, mesh sends и dataplane
writes. Control trace context передаётся через gRPC metadata и HTTP upstream;
public opaque payload не получает trace fields. SQL, DSN и domain identities
не попадают в span attributes; ошибки отмечаются фиксированным статусом.
Fatal events различают registry_unavailable/trust_unavailable/workload_expired/
listener_failed/control_failed/dataplane_failed; labels/logs имеют конечный набор.


Mesh metrics различают queue_full/queue_bytes/global_bytes/peer_not_ready/
fenced/stream_reset/incoming_reset/other; cardinality фиксирована, peer IDs
и исходные transport errors не являются labels. Один переиспользуемый
watchdog на исходящий stream ограничивает actual Send двумя секундами и
ранним grant deadline; истечение закрывает owning ClientConn и прерывает
flow-controlled Send. Служебные server Send имеют отдельный bounded handler.


Отдельный product suite включает IPv6 public TLS, payload1/65536 и strict
malformed rejection, отказ authority, clean fast shutdown test PostgreSQL,
истечение текущего synthetic Workload API SVID и unavailable HTTPS exporter.
Recovery tests явно перезапускают один test Coordinator (и test registry);
автоматический production restart/failover ими не подтверждается. Unit-only CI
эти suites не запускает. `golangci-lint run --build-tags=product ./tests/product`
проверяет дополнительный тестовый код тем же public lint profile.
